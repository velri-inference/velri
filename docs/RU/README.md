# Документация Velri

[English](../EN/README.md)

**Velri** — нативный движок инференса нейросетевых моделей для Windows, Linux и Android, рассчитанный в том числе на запуск моделей, чьи веса не помещаются целиком в память GPU. Языки реализации — **C23** и **C++23** (с публичным C23 API, без Python и PyTorch в рантайме). Первые целевые бэкенды — **CPU и Vulkan**; единый язык оптимизированных кернелов для GPU и CPU — **Khronos Slang** (`slangc`, AOT-компиляция при сборке).

Вычисления, граф запуска кернелов и бэкенды устройств вынесены в библиотеку **`velri-lib/`** внутри этого же репозитория. Документация разделена без дублирования: всё о библиотеке живёт в `velri-lib/docs/RU/`, всё о движке и моделях — здесь.

---

## Что работает сейчас

- В `velri-lib/` работает Slang-first библиотека **`VelriLib::cpu`** (`<velri_lib/kernels.h>`, обязательный `slangc` AOT при сборке) и опциональный Vulkan-бэкенд **`VelriLib::vulkan`** (`-DVELRI_ENABLE_VULKAN=ON`): 23 CPU-кернела (`GEMV`/`GEMM` по `F64`, `FP32`, `FP16`, `BF16`, `W8A8`, `W8A32`, `RMSNorm`, `Add+RMSNorm`, `LayerNorm`, `RoPE`, активации, `GatedMLP`, `Softmax`, `FWHT`, `QuantRow`, преобразования форматов) поверх `velri_pool` и 35 SPIR-V 1.6 шейдеров (`CoopMat`, `Split-K`), с независимой проверкой на C23-эталонах ([Кернелы на Slang](../../velri-lib/docs/RU/kernels.md)). Прежний ручной C23/SIMD-бэкенд сохранён в архивной ветке `archive/c23-cpu-legacy`.
- В корне собирается интеграционный тест потребителя `VelriLib::cpu` (`tests/integration/velri_lib.c`).
- Вычислительный граф, реестр бэкендов, планировщик памяти, загрузка весов и инференс реальных моделей — целевая архитектура в разработке ([план работ](roadmap.md)).
