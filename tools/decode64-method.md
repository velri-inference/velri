# Measuring single-request W8A8 decode

Fix the workload and references before changing a kernel. Use the complete TinyLlama/TinyLlama-1.1B-Chat-v1.0 checkpoint at revision `fe8a4ea1ffedaf415f4da2f062534de366a451e6`. If the checkpoint cannot be retrieved, use the locally available full GPT-2 small checkpoint and record the substitution before collecting baseline data. Use the same converted weights and token IDs in every comparison. Signed INT8 matrices have one FP32 scale per output channel. The graph quantizes activations per token. Include all layers, vocabulary projection, attention and KV updates.

Compare the kernels in `6fa401e0` with the candidate. Give both versions the identical production model binding and execution path, benchmark and model data. Begin with a separate profile of a complete sequence. Use that profile to choose candidate changes. Hold back the candidate unless it passes a full decode correctness check and improves its target workload.

## Timed session

Use a Release build, single request, 128 prompt tokens and 64 successive greedy one-token calls. Feed each sampled ID into the next call. Measure wall clock around all 64 calls, including readback, synchronization and sampling. Exclude conversion, model preparation, prefill and two complete warmup sequences. Start three separate processes per revision and device. Each process times one sequence. Interleave builds (AB, BA, AB), run one benchmark process at a time and save each elapsed time. Report arithmetic mean milliseconds and tokens/s from total tokens divided by total time. Keep automatic clocks and the same CPU affinity, shader driver and pool size across the comparison. On this 9950X, CPUs 0–15 span all 16 physical cores. Explicitly select AVX2 and AVX-512 in turn. Use the NVIDIA ICD on the RTX 5070 Ti.

## Profile and ceilings

Profile each backend separately from wall-clock measurements. Group actual dispatches by kernel and tensor geometry. Count one MAC as two useful operations. For GEMV with one token, input width K and output width M, count 2MK operations and at least MK + K + 8M + 4 bytes for signed weights and activations, both FP32 scales, and FP32 output. Include optional bias reads when present. Use summed work divided by summed time for each group. Count a fused dispatch once. Record the convention for each elementwise, attention and transfer operation, with GB/s for pure data movement. Distinguish logical tensor bytes from measured DRAM traffic. Attention lengths run from 129 through 192. Report device time and end-to-end time separately.

Preserve the independently measured streaming read bandwidth of 69.40 / 70.50 / 838.196 GB/s (AVX2 / AVX-512 / RTX) and compute references of 4.779 / 22.193 / 393.425 dense INT8 TOPS and 2.760 / 5.540 / 47.410 FP32 TFLOPS. CPU read calibration streams 1 GiB with 16 physical cores, GPU read streams 512 MiB with CUDA. Compute calibrations run register-resident SIMD or GPU FMA/MMA on the same devices. AVX2 uses widened signed pairs, AVX-512 uses VNNI. The GPU dense tensor peak is a hardware reference even when the actual GEMV uses integer dot instructions on the SMs. Nominal memory interfaces provide 96 / 96 / 896 GB/s. For each arithmetic group the streaming roof is min(compute peak, bandwidth × useful operations / logical bytes). Percent departure is 100 × (observed / reference − 1). For pure copies use the bandwidth reference directly and leave arithmetic fields inapplicable.

The 90% test uses the original streaming roof on whole-model W8A8 projection traffic, with all individual shapes reported. Also report a projection-only best-case token rate from unique projection weight and scale bytes per token, then compare full session throughput to it. Small tensors can be served from caches. Launch, barriers, reductions, sampling and transfers contribute time in the real session. Document a shortfall with comparative measurements. Keep the original reference visible when measuring an additional hardware or dispatch limit.

For verification, compare every sampled ID and the logits at prefill and each of the 64 positions across baseline and candidate on matching inputs. Record the maximum absolute and relative L2 error or exact equality. Check a float or independent quantized reference to catch a shared graph/weight-loading error. Run the repository correctness suite, its portable CPU build and an AVX2-without-VNNI correctness check. Only target hardware timings count toward performance.
